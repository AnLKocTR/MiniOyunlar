# MiniOyunlar

Java Swing ile hazırlanmış beş mini oyunluk masaüstü uygulaması.

## Gereksinimler

- JDK 21 veya üzeri
- Eclipse IDE (isteğe bağlı)

Eclipse'te Java projesi olarak içe aktarın ve `MiniOyunlar.MiniOyunlar` sınıfını çalıştırın. Rekorlar kullanıcı klasöründe tutulur. İsteğe bağlı görselleri `resimler/` klasörüne ekleyebilirsiniz.
